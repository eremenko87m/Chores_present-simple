# Chore Wars v10 — GitHub Pages

Upload the contents of this folder to the root of your GitHub repository.

Required files:
- index.html
- .nojekyll
- assets/

Teacher controls:
- BACK and NEXT are always available for checking slides and moving freely.
- Missions are completed only with the separate COMPLETE MISSION button.
- NEW PROMPT in Mission 2 only changes the speaking prompt.
- MUSIC ON/OFF controls the lightweight browser-generated background music.
- SOUND ON/OFF controls game sound effects.

Room unlock animation appears after COMPLETE MISSION. Use BACK TO MISSION or NEXT MISSION on that screen.
